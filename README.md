# Matheo Flores — Portafolio

Portafolio personal de **Matheo Flores**, desarrollador web full-stack en Quito, Ecuador.

Sitio en vivo: [matheoflores.dev](https://matheoflores.dev)

## Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- [Supabase](https://supabase.com) (base de datos, auth y storage)
- [Tailwind CSS](https://tailwindcss.com) + [Framer Motion](https://www.framer.com/motion/)
- [next-intl](https://next-intl.dev) (español / inglés)

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

Necesitás un archivo `.env.local` con las variables de Supabase (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`) para que carguen proyectos, servicios y mensajes reales.
